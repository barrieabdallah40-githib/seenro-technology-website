SEENRO Core

A backend platform we are building from the ground up.

SEENRO Core is a backend written in Rust with Axum and SQLite. It is under active development and runs on a development machine. It is not yet deployed to the public internet, and there is no public API to connect to.

Working locally Tested

  • Account registration and login, with passwords hashed using Argon2.
  • Session tokens that expire, are stored hashed, and can be revoked at logout.
  • Private per-user notes, as a first example of user-owned data.
  • Rate limiting on login and registration, plus a growing delay after repeated failed logins.
  • Request size limits and an automated test suite covering these features.

In development In development

  • Deployment on a small server with HTTPS and a reverse proxy.
  • Per-user limits and pagination for stored data.
  • Monitoring and backups.

Planned Planned

  • A public API for developers.
  • Documentation with example requests and responses.
  • A service status page.
  • A way to report bugs and request features.

We update this page as things change. Source code and documentation will be linked here when they are ready to publish.
