A backend foundation for your next project.

SEENRO Core is the deployed foundation of the SEENRO developer platform. It provides developer identity, project management, scoped credentials, project data operations and an initial project storage API.

Security model

Credentials have distinct roles.

Developer sessions

Used by the portal to manage the signed-in developer's projects and credentials.

Developer API keys

Project-bound secrets intended for trusted server-to-server integrations. Never expose them in browser or mobile application code.

Storage keys

Separate project storage credentials with their own management and authentication contract.

Storage

Project file storage

The documented foundation includes a shared 100 MiB free account allocation and project-specific paid capacity. Current file limits, video requirements, pricing and payment safeguards are maintained in the live documentation.
