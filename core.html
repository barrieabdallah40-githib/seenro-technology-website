SEENRO Backend-as-a-Service

Build your applications. We'll power the backend.

SEENRO provides Backend-as-a-Service (BaaS) for developers. Powered by SEENRO Core, the platform brings together developer accounts, project management, scoped credentials and project data operations. It is one of SEENRO Technology's services, built to help developers create digital products without building every backend foundation themselves.

Current platform capabilities

What the platform supports today.

The following describes the capabilities implemented in the current SEENRO Core codebase. Individual integrations and operational limits should always be checked against the current developer documentation.

Developer authentication

Developer registration, login, session management and account access are implemented in Core.

Project management

Developers can create and list projects and use project-bound credentials to access supported capabilities.

API keys and scopes

Developer API keys are associated with projects and support defined permissions for supported API operations.

Collection and record operations

Project-scoped data operations are implemented for working with application collections and records.

Storage metadata and usage

Storage-related metadata and usage operations are present. These should not be interpreted as confirmation that complete file upload and download functionality is available.

Direct file uploads

Complete direct file-upload and download functionality is not advertised as currently available. Developers should not depend on it until the relevant handlers and end-to-end integration have been implemented and verified.

An implemented API route does not automatically mean every external integration or end-to-end workflow has been verified. Consult the current documentation for supported endpoints, limitations and integration requirements.

Security

Designed with project separation in mind.

SEENRO Core uses project-bound credentials and scoped access controls to help separate application resources. Developer secret API keys are intended for trusted server-side use only. Never expose secret keys in public browser code, mobile applications, client-side bundles or public repositories. Use only the credentials and permissions appropriate to each integration.
