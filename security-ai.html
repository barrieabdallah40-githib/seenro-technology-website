Security and AI

Defensive security research, starting with the basics.

This is our longer-term direction. No AI models or security products exist yet, and nothing on this page should be read as a finished tool.

Direction

  • AI-assisted detection of vulnerabilities.
  • Spotting suspicious activity and automated attacks.
  • Security tools for developers and small businesses.
  • AI solutions for practical problems in Sierra Leone.

How we will approach it

  • Defensive and responsible work only.
  • Open-source models and affordable computing first, not training large models from scratch.
  • Measure accuracy and false positives before releasing anything.
  • Practice on our own systems first. SEENRO Core is the first test subject.

What exists today

The security work happening now is on SEENRO Core: hashed passwords and tokens, rate limiting, input limits and a growing test suite. If you work in cybersecurity or AI and want to help, get in touch.
